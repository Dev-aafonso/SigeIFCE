Informações gerais

Configurações

Defina as preferências para inscrições, certificados e comunicação do evento.

Essas preferências são exibidas e incluídas na revisão do formulário, mas ainda não são persistidas: a API atual não possui campos para elas.

Programação do evento

Adicione pelo menos uma ação para habilitar a publicação. A duração é calculada pelos horários informados.

Revise antes de salvar

O evento será criado como rascunho. Você poderá revisar e publicar depois que a API confirmar os dados.
